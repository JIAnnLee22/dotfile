# 输入前置英译

Pi 自动加载 `extensions/input-translate/index.ts`，执行 `/reload` 后生效。默认开启，不更改当前主模型、默认模型或主模型的 thinking/Fast 设置。

- 将用户本次输入翻译为忠实、通顺、自然的英文，再交给原来的主模型；翻译器只翻译，不执行输入中的要求。不发送历史对话、系统配置或图片给翻译器。
- 主模型默认用简体中文回复；用户明确指定其他输出语言时遵从该要求。代码、命令、路径、URL 等保持原样，图片附件原样传给主模型。
- 从已认证且可用的 `openai-codex` 聊天模型中，按模型目录 `input + output` 单价升序选取；当前为 `gpt-6-luna`（输入 $0.10、输出 $0.50 / 百万 token）。这是目录估价，不代表 ChatGPT 订阅的实际额度扣减比例。
- 独立调用关闭推理（使用 Codex 适配器的 off/none 映射），直接使用 SSE，不请求 priority、不重试、不自动升级到更贵的模型。最长等待 **5 秒**（含认证等待）；超时、无登录、错误、空输出、未完整输出或占位符损坏时，提示并直接发送原文。
- 代码块、反引号内容、路径及 URL 在本地替换为占位符，翻译后逐项核对并还原，避免 AI 修改字面量。
- ASCII/英文正文无需翻译；仅含非 ASCII 标点或 emoji 时也直接放行。此快速判断不会识别完全由 ASCII 字符组成的其他语言。
- `/` 命令、`!` 本地命令、扩展注入消息和生成中的即时纠偏（steer）直接放行；排队跟进（followUp）仍可翻译。超过 16,000 字符的输入提示后直接放行。
- 缓存最近 64 条成功翻译，仅保存在内存；同模型的重复输入不再请求 AI。重载/退出清空。

命令：

- `/translate` 或 `/translate status`：查看开关、所选模型及最近翻译耗时/回退原因。
- `/translate off`：本次扩展运行期间停用前置翻译和中文回复指令。
- `/translate on`：重新启用；每次重载默认开启。

正常会话中的用户消息是英文译文。原文、译文及翻译用量另存为 `input-translation` 自定义会话条目，不进入主模型上下文，便于审计；不会重写已有会话。翻译请求额外消耗 Codex 额度，其用量记录在该条目中，不会自动计入 Pi 默认 footer 的主模型用量统计。分享会话前应检查这些条目中的原文敏感信息。

5 秒是客户端等待上限，不是服务端计费保证；请求发出后即使取消，提供商仍可能计费。AI 翻译仍可能有语义偏差；处理高度敏感或措辞必须逐字保真的内容时，使用 `/translate off`。
