# 本地多维 TPS 扩展

来源：[@monotykamary/pi-tps](https://github.com/monotykamary/pi-tps) `1.3.16`，MIT 许可证见 `LICENSE`；原始上游说明见 `README.upstream.md`。本地实现由此配置仓库维护，不通过 npm 更新。

Pi 自动发现 `extensions/tps/index.ts`，无需安装额外依赖。修改后执行 `/reload`，不要同时启用 npm 版 TPS。

## 页脚与命令

默认保留 Pi 的 footer，在扩展状态栏显示指标，生成过程中每 1000 ms 刷新，结束后保留最终统计。不自动弹出 TPS 通知。

- `/tps`：查看当前生成或当前分支最近一次生成的多维详情。
- `/tps full`：页脚增加峰值、耗时、缓存读写、工具时间和费用。
- `/tps compact`：恢复默认精简页脚。

显示模式仅在当前扩展运行期间有效，重载后恢复 compact。Pi 会将所有扩展状态拼在同一行，窄终端可能截断；可用 `/tps` 查看未截断的详情，不替换其他插件的 footer。

示例（数值仅作格式说明）：

```text
TPS 1s:~42.0 3s:~39.0 avg:~38.0 e2e:~30.0 · TTFT 1.2s · out ~180
TPS 45.0 tok/s · avg:40.0 · e2e:31.0 · TTFT 1.2s · out 210 · cache:75%
```

## 速率维度（单位均为 tok/s）

| 指标 | 含义与计量边界 |
| --- | --- |
| `1s` | 最近约一次刷新间隔内的内容增量 / 实际间隔；停顿时下降到 0 |
| `3s` | 最近约 3 秒的平滑速率，减小单个数据块抖动；使用刷新采样点，受调度延迟影响 |
| `avg` | 本轮输出 / 首个流式更新到消息结束的累计时间；排除 TTFT、消息间工具空档，但不扣停顿 |
| `e2e` | 本轮输出 / `turn_start → turn_end` 总时间；包括首字等待和本轮工具时间 |
| 最终 `TPS` | 上游停顿扣除、主分支判断及保守回退算法计算的生成速率，不等于简单平均 |
| `peak` | 本轮采样到的最高近 1 秒速率，不是瞬间硬件峰值；不足一个可靠采样区间时为 `—` |

`1s`、`3s`、`peak` 始终以 Pi 的 `estimateTokens()` 估算内容增量并标 `~`，不会把最后一次服务端用量校准误判成速率尖峰。采样历史只保留滑动窗口所需的少量点。

实时 `avg`、`e2e`、`out` 优先使用服务端已报告的输出 token；未报告时估算内容并标 `~`。估算受语言、思考内容、工具参数和分词器影响，不等于真实 token 数。最终使用服务端报告的用量；无法可靠计量或异常高于 10,000 tok/s 时显示 `—`，不制造精确值。

所有统计均为单轮请求，不是整个会话的平均值；生成平均与端到端按不同时间口径分别展示。

## 其他维度

- **延迟**：TTFT（本轮首个流式更新）、生成时间、总耗时。
- **用量**：非缓存输入、输出、缓存读取、缓存写入和总 token。输入通常到生成结束才完整，未报告时不假定已知。
- **缓存命中**：`cacheRead / (input + cacheRead + cacheWrite)`；分母未知/为零显示 `—`，不将输出计入命中率。
- **停顿**：间隔达到 500 ms 的流式停顿总时长及次数；实时包含尚未恢复的等待间隔，不把 TTFT 或工具执行当作流式停顿。
- **工具时间**：本轮工具执行区间的并集；并行/嵌套工具不重复累加。
- **费用**：优先 Neuralwatt 账单事件，否则显示模型目录估价；无价格时显示 `—`。支持 `$/M` 混合费率，费用来源不重复相加。
- **诊断**：消息数和流式更新次数。最终遥测保留在会话 `tps` 自定义条目，发布 `tps:telemetry` 事件。

## 兼容与导出

已有 `tps`、`timing`、`tokens`、`cost` 字段保持兼容。新记录增加可选 `metrics` 对象（`version: 1`），保存 `averageTps`、`endToEndTps`、`peakTps`、`peakEstimated`、`generationMs`、`toolMs`、`updateCount`、`cacheHitPercent`、`costUsd` 与 `costSource`。恢复历史记录时缺少的新指标显示 `—` 或省略；继续支持旧 `{ message, timestamp }` 格式。

- `/tps-export [自定义条目类型] [--full]`：导出遥测及模型切换/分支结构，重连 parentId，保留新 metrics。
- `/session-export [--full]`：导出完整会话条目。

默认导出当前分支，`--full` 导出所有分支，保留命令补全。文件分别写入 `${XDG_CACHE_HOME:-~/.cache}/pi-telemetry/` 和 `${XDG_CACHE_HOME:-~/.cache}/pi-sessions/`，并尝试打开目录。会话导出可能包含提示词、工具结果及敏感信息，分享前需检查。

定时器只在有 UI 的生成过程中运行，结束、取消、会话切换、重载或关闭时清理；不会在扩展工厂中启动后台资源。
