# Plan Mode Extension (优化版)

安全的只读探索模式，用于代码分析和计划制定。

## ✨ 改进特性

### 🎨 UI 改进
- **进度条可视化** - 使用 `█░` 字符显示执行进度
- **Emoji 图标** - ✅ 完成 / ⬜ 待执行 / ⏭️ 跳过 / 🚀 执行中
- **中文界面** - 所有提示和状态信息使用中文
- **实时状态栏** - 底部显示当前模式和进度
- **小组件显示** - 详细的任务列表和进度信息

### 🔄 流程改进
- **更清晰的模式切换** - 明确的启用/禁用提示
- **步骤跳过支持** - 使用 `[SKIP:n]` 标记跳过步骤
- **自动完成检测** - 检测所有步骤完成后自动退出执行模式
- **更友好的取消选项** - 可以取消计划而不执行

### 📊 进度跟踪
- **进度条** - 可视化显示完成百分比
- **实时更新** - 每轮结束后自动更新状态
- **统计信息** - 显示完成/跳过/总计数量

## 📦 安装

将以下文件放到 `~/.pi/extensions/plan-mode/` 目录：

```
~/.pi/extensions/plan-mode/
├── index.ts      # 主扩展文件
├── utils.ts      # 工具函数
└── README.md     # 本文档
```

## 🎯 使用方法

### 命令
- `/plan` - 切换计划模式
- `/todos` - 显示当前计划进度

### 快捷键
- `Ctrl+Alt+P` - 切换计划模式

### 工作流程

1. **启用计划模式**
   ```
   /plan
   ```

2. **分析代码并创建计划**
   ```
   请分析这个项目的认证模块，并创建重构计划
   ```

3. **AI 会创建类似这样的计划**：
   ```
   Plan:
   1. 分析现有的认证逻辑
   2. 识别需要修改的函数
   3. 设计新的认证流程
   4. 实现修改
   5. 添加测试
   ```

4. **选择执行计划**
   - 🚀 执行计划（跟踪进度）
   - 📝 继续完善计划
   - ❌ 取消计划

5. **执行过程中**
   - AI 会自动标记完成的步骤 `[DONE:n]`
   - 可以跳过某些步骤 `[SKIP:n]`
   - 进度会实时显示在状态栏和小组件中

## 🔒 安全特性

### 允许的命令（计划模式下）
- 文件查看: `cat`, `head`, `tail`, `less`, `more`
- 搜索: `grep`, `find`, `rg`, `fd`
- 目录: `ls`, `pwd`, `tree`
- Git 只读: `git status`, `git log`, `git diff`, `git branch`
- 包信息: `npm list`, `npm outdated`, `yarn info`

### 阻止的命令
- 文件修改: `rm`, `mv`, `cp`, `mkdir`, `touch`
- Git 写入: `git add`, `git commit`, `git push`
- 包安装: `npm install`, `yarn add`, `pip install`
- 系统: `sudo`, `kill`, `reboot`
- 编辑器: `vim`, `nano`, `code`

## 🔧 配置

可以通过 `--plan` 参数以计划模式启动：

```bash
pi --plan
```

## 📋 状态持久化

计划状态会自动保存到会话中，即使重启 pi 也会恢复：

- 计划模式启用状态
- 当前计划步骤
- 执行进度

## 🎨 自定义

如需修改 UI 或行为，可以编辑以下文件：

- `index.ts` - 主逻辑和 UI 显示
- `utils.ts` - 工具函数（命令检查、计划解析）

## 🐛 故障排除

### 计划没有被识别
确保 AI 使用了正确的格式：
```
Plan:
1. 步骤描述
2. 步骤描述
```

### 命令被阻止
在计划模式下只能使用只读命令。如需执行修改，请先退出计划模式。

### 进度没有更新
确保 AI 在完成步骤后包含 `[DONE:n]` 标记。
