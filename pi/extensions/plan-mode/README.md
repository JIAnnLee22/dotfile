# Plan Mode Extension (优化版)

安全的只读探索模式，用于代码分析和计划制定。

## 功能特性

### UI 改进
- **右上角悬浮窗口** - 计划列表显示在右上角浮动窗口中
- **可滚动** - 支持键盘滚动浏览长计划列表
- **颜色主题** - 使用主题颜色显示不同状态
- **实时状态栏** - 底部显示当前模式和进度

### 流程改进
- **更清晰的模式切换** - 计划模式 → 执行模式 → 正常模式
- **步骤跳过支持** - 使用 `[SKIP:n]` 标记跳过步骤
- **管道命令支持** - 只读组合命令可放行
- **自动完成检测** - 所有步骤完成后自动退出执行模式

### 进度跟踪
- **进度条** - 可视化显示完成百分比
- **编号一致** - 列表显示、`[DONE:n]`、`[SKIP:n]` 均使用 Plan 中的步骤号

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `/plan` | 切换计划模式 |
| `/todos` | 显示当前计划进度 |
| `Ctrl+Alt+L` | 切换计划模式 |
| `Ctrl+Alt+P` | 显示/隐藏计划悬浮窗口 |

## 悬浮窗口操作

当计划悬浮窗口打开时：

| 按键 | 功能 |
|------|------|
| `j` / `↓` | 向下滚动 |
| `k` / `↑` | 向上滚动 |
| `PageDown` | 向下翻页 |
| `PageUp` | 向上翻页 |
| `Home` | 跳转到开头 |
| `End` | 跳转到结尾 |
| `Esc` | 关闭窗口 |
| `Ctrl+Alt+P` | 关闭窗口 |

## 工作流程

1. `/plan` 启用计划模式
2. 让 AI 分析并输出 `Plan:\n1. [文件路径] 修改描述\n2. ...`
3. 计划会自动显示在右上角悬浮窗口中
4. 按 `Ctrl+Alt+P` 可随时显示/隐藏计划窗口
5. 选择 **执行计划** 开始执行
6. AI 每完成一步输出 `[DONE:n]`
7. 全部完成后自动显示摘要并恢复工具

## 计划格式

```
Plan:
1. [src/auth/login.ts] 在 login 函数中添加参数验证逻辑
2. [src/utils/validators.ts] 创建 validateEmail 辅助函数
3. [tests/auth.test.ts] 添加登录验证的单元测试
```

## 故障排除

### 计划没有被识别
确保使用 `Plan:` 标题与 `1.` / `2.` 编号列表。

### 命令被阻止
- 确认每段管道均为只读命令
- 避免 `2>/dev/null` 以外的重定向
- 需要修改文件时使用 `/plan` 退出计划模式，或进入执行模式

### 悬浮窗口不显示
- 确保已创建计划（需要有计划步骤才能显示）
- 按 `Ctrl+Alt+P` 尝试切换显示
