# 中文模式 (Chinese Mode)

本 Skill 强制 AI 在整个对话过程中使用中文进行思考和输出。

## 核心规则

### 1. 思考语言
- **必须使用中文进行思考和推理**
- 即使代码是英文，思考过程也要用中文表达
- 内部独白、分析、决策全部使用中文

### 2. 输出语言
- 所有对话回复使用中文
- 代码注释使用中文
- Git 提交信息使用中文
- 错误信息和警告使用中文描述
- 文档和 README 使用中文

### 3. 代码规范
- 变量名、函数名保持英文（编程规范要求）
- 但代码注释必须是中文
- 配置文件中的注释使用中文
- 日志输出使用中文

## 使用方法

### 启用中文模式
在对话开始时说：
```
/skill:chinese-mode
```
或直接说：
```
启用中文模式
```

### 禁用中文模式
```
禁用中文模式
```
或
```
切换到英文模式
```

## 中文输出示例

### 代码注释
```javascript
// 计算用户年龄（从出生日期计算）
function calculateAge(birthDate) {
  // 获取当前日期
  const today = new Date();
  // 计算年龄差
  const age = today.getFullYear() - birthDate.getFullYear();
  return age;
}
```

### Git 提交信息
```
feat: 添加用户登录功能

- 实现 JWT token 认证
- 添加密码加密处理
- 优化错误提示信息

Fixes #123
```

### 错误处理
```typescript
try {
  // 尝试读取配置文件
  const config = await readConfig();
} catch (error) {
  // 配置文件读取失败，使用默认配置
  console.error('配置文件读取失败，使用默认配置:', error);
  config = defaultConfig;
}
```

## 特殊场景处理

### 1. 代码中的英文标识符
保持英文，但注释用中文：
```python
# 数据库连接配置
DATABASE_CONFIG = {
    'host': 'localhost',  # 数据库主机地址
    'port': 5432,         # 数据库端口
    'name': 'myapp'       # 数据库名称
}
```

### 2. 技术术语
首次出现时可以中英对照：
```
应用程序接口（API）
模型上下文协议（MCP）
大语言模型（LLM）
```

### 3. 命令行输出
```
正在编译项目...
编译完成！共处理 42 个文件
警告：发现 3 个未使用的导入
```

## 注意事项

1. **不要强制翻译变量名** - 变量名、函数名、类名保持英文
2. **技术文档可以中英混用** - 某些技术文档可以保留英文原文
3. **错误堆栈保持英文** - 系统错误信息通常保持原样
4. **代码关键字保持英文** - if, for, while, function 等保持英文

## 持久化

本 Skill 的设置会持续生效，直到：
- 用户明确禁用中文模式
- 会话结束
- 用户切换到其他语言模式
