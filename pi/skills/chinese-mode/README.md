# 中文模式 Skill 使用说明

## 功能概述

中文模式是一个 Pi 编码代理 Skill，用于强制 AI 在整个对话过程中使用中文进行思考和输出。

## 主要功能

- ✅ 强制中文思考和推理
- ✅ 中文对话输出
- ✅ 中文代码注释
- ✅ 中文 Git 提交信息
- ✅ 中文文档生成
- ✅ 中文错误信息

## 快速开始

### 启用中文模式

在 Pi 对话中输入：

```
/skill:chinese-mode
```

或直接说：

```
启用中文模式
```

### 禁用中文模式

```
禁用中文模式
```

或

```
切换到英文模式
```

## 使用场景

### 1. 长时间编码会话

当你希望 AI 在整个编码过程中保持中文输出：

```
用户：启用中文模式
用户：帮我实现一个用户认证模块
AI：好的，我来实现用户认证模块。首先分析需求...
```

### 2. 团队协作

当团队需要中文代码注释和文档时：

```
用户：启用中文模式，然后帮我写一个 REST API
AI：好的，我将使用中文注释来编写这个 REST API...
```

### 3. 文档编写

生成中文技术文档：

```
用户：启用中文模式，为这个项目写 README
AI：好的，我将生成中文版本的 README 文档...
```

## 输出示例

### 代码注释风格

```typescript
/**
 * 用户管理服务
 * 处理用户的创建、更新、删除和查询操作
 */
export class UserService {
  /**
   * 创建新用户
   * @param userData 用户数据
   * @returns 创建成功的用户对象
   */
  async createUser(userData: CreateUserDto): Promise<User> {
    // 验证用户数据
    this.validateUserData(userData);

    // 加密密码
    const hashedPassword = await this.hashPassword(userData.password);

    // 保存到数据库
    return this.userRepository.create({
      ...userData,
      password: hashedPassword,
    });
  }
}
```

## 配置选项

中文模式支持以下配置（在 SKILL.md 中修改）：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 思考语言 | 中文 | AI 内部推理使用的语言 |
| 输出语言 | 中文 | 对话回复使用的语言 |
| 代码注释 | 中文 | 代码中注释的语言 |
| 变量命名 | 英文 | 变量、函数名保持英文 |

## 注意事项

1. **变量命名保持英文** - 编程规范要求变量名使用英文
2. **技术术语可中英对照** - 首次出现时可以中英对照显示
3. **错误堆栈保持英文** - 系统错误信息通常保持原样
4. **代码关键字保持英文** - if, for, while 等关键字保持英文

## 常见问题

### Q: 为什么变量名不翻译成中文？

A: 编程规范要求变量名使用英文，这样可以：
- 保持代码的国际通用性
- 避免编码问题
- 方便与其他开发者协作

### Q: 可以混合使用中英文吗？

A: 可以。技术文档和注释可以中英混用，但主要描述性内容建议使用中文。

### Q: 中文模式会影响代码执行吗？

A: 不会。中文模式只影响 AI 的输出语言，不影响代码的执行。
